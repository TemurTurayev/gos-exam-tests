# Файлы без ключа правильных ответов

В этих 6 файлах нет никакой разметки правильного ответа — ни символов
(`+`/`-`/`*`), ни жирного шрифта, ни цвета, ни отдельного списка ответов.
Это "чистые" банки вопросов без ответов, поэтому их не включили в сайт
(чтобы не гадать и не показывать неверные ответы как правильные).

- `102-bol-hirurgia-test-sajt-uzb-495 (1).pdf` — Детская хирургия (узб.)
- `Pediatriya javob 98%aniq 99.pdf` — Педиатрия (узб.)
- `bolalar xirurgiyasi rus.pdf` — Детская хирургия (рус.)
- `Детская хирургия....✓.pdf` — Госпитальная детская хирургия (рус., с указанием источника/главы)
- `Пед рус...✓.pdf` — Педиатрия (рус., с указанием источника/главы)
- `terapiya rus baza test.doc` — Терапия (рус.) — жирным выделен весь вопрос, а не ответ, разметки нет

Что можно сделать позже:
1. Найти оригинальные файлы с ключами ответов (возможно, существуют отдельно).
2. Вручную сверить с учебником/методичкой и проставить ответы.
3. Добавить в сайт как "тренировочный" режим без проверки (вопрос + варианты, без начисления баллов).
