# Файлы без явного ключа правильных ответов

В этих 6 файлах нет разметки правильного ответа (ни символов `+`/`-`/`*`, ни
жирного шрифта, ни цвета, ни строки «правильный ответ»). Поэтому они не вошли
в основную базу сайта.

## Проверка гипотезы «правильный ответ — всегда первый вариант»

Проверяли двумя независимыми способами:

1. **Сверка с базой.** Ищем тот же вопрос в файлах, где ответ размечен, и
   смотрим, на какой позиции стоит заведомо правильный вариант
   (`scripts/check_unanswered.py`).
2. **Медицинская проверка** случайной выборки вопросов вручную.

| Файл | Тема | Гипотеза «первый вариант» |
|---|---|---|
| `Детская хирургия....✓.pdf` | Госпитальная детская хирургия (рус.) | **Подтверждается**: сверка 3/3, медицинская проверка 6/6 |
| `Пед рус...✓.pdf` | Педиатрия (рус.) | **Подтверждается**: медицинская проверка 6/6 |
| `terapiya rus baza test.doc` | Терапия (рус.) | **Скорее да**: сверка 15/16, но 1–2 вопроса из выборки вызывают сомнение |
| `102-bol-hirurgia-test-sajt-uzb-495 (1).pdf` | Детская хирургия (узб., латиница) | **Опровергается** — варианты перемешаны |
| `Pediatriya javob 98%aniq 99.pdf` | Педиатрия (узб., латиница) | **Опровергается** — варианты перемешаны |
| `bolalar xirurgiyasi rus.pdf` | Детская хирургия (рус.) | **Опровергается** — варианты перемешаны |

Примеры, опровергающие гипотезу:

* `Pediatriya javob…` — «Stridor bu…»: верный ответ — стеноз **верхних**
  дыхательных путей (4-й вариант, не 1-й). «Bosh suyagi aylanasi» — верно
  33–34 см (2-й вариант).
* `102-bol-hirurgia…` — «Noto'liq kindik oqmasi diagnostikasi»: верно
  зондирование (3-й вариант); подтверждается русской версией того же вопроса.
* `bolalar xirurgiyasi rus.pdf` — «Основные симптомы ахалазии пищевода»:
  верно «дисфагия и регургитация» (3-й вариант).

## Что дальше

Три верхних файла (≈2 500 вопросов) можно добавить на сайт, приняв правило
«верен первый вариант», — но их стоит пометить как восстановленный ключ.
Три нижних требуют настоящего ключа: либо оригиналы с ответами, либо ручная
сверка с учебником.
