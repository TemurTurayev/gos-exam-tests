# Гос экзамен — тесты

Тренажёр для подготовки к государственному экзамену: терапия, педиатрия,
хирургия, детская хирургия, акушерство и гинекология на русском и узбекском.

**Сайт:** https://temurturayev.github.io/gos-exam-tests/

- **5 747 вопросов** в 16 наборах;
- **общий пул** — все предметы вперемешку;
- сайт **помнит, что уже решено**, и умеет выдавать только новые вопросы или
  только те, где была ошибка;
- работает на телефоне и на компьютере, есть **офлайн-версия одним файлом**
  (`gos-exam-tests-offline.html`) — скачал и открыл двойным кликом, интернет
  не нужен;
- прогресс хранится в браузере пользователя (localStorage), сервер не нужен.

## Откуда берутся вопросы

Исходники — файлы `.doc/.docx/.pdf/.txt`, у каждого своя разметка правильного
ответа: символы `+`/`-`, `#`, `*`, жирный шрифт, отдельная колонка таблицы,
строка «Правильный ответ: …» или стрелка `←правильный ответ`.

```bash
python3 scripts/parse.py          # исходники -> data/*.json
python3 scripts/verify.py         # независимая проверка ключей
python3 scripts/build_offline.py  # сборка офлайн-версии одним файлом
```

### Проверка правильности ответов

`parse.py` публикует вопрос только если его правильный ответ **подтверждён**
разметкой исходника: логика проверки написана отдельно от парсера
(`marked_texts`), и всё, что не сошлось, отбрасывается. Сейчас отброшен 51
спорный вопрос, `verify.py` показывает 0 неподтверждённых.

Часть вопросов имеет **несколько правильных ответов** («перечислите 3 формы…»)
— они хранятся списком и в интерфейсе требуют выбрать все верные варианты.

## Структура

```
data/            банки вопросов в едином JSON-формате + manifest.json
js/              storage.js (прогресс), data.js (загрузка), ui.js, app.js (экраны)
scripts/         parse.py, verify.py, check_unanswered.py, build_offline.py
sources/         исходные файлы (в git не попадают)
```

Формат вопроса:

```json
{ "q": "текст вопроса", "options": ["…", "…"], "correct": [0] }
```

## Файлы без ключа ответов

Шесть исходников не содержат разметки правильного ответа. Они лежат отдельно
в `sources/without_answers/` — там же разбор гипотезы «правильный ответ всегда
первый»: для трёх файлов она подтверждается, для трёх опровергается.
Подробности — в `sources/without_answers/README.md`.
