# Гос экзамен — тесты

Тренажёр для подготовки к государственному экзамену: терапия, педиатрия,
хирургия, детская хирургия.

**Сайт:** https://temurturayev.github.io/gos-exam-tests/

- **8 898 вопросов** в 21 наборе;
- **вход по имени** — прогресс каждого человека хранится отдельно;
- **два языка**: интерфейс и тесты переключаются между русским и узбекским;
- **общий пул** — все предметы вперемешку, с памятью решённого;
- фильтры «только нерешённые» и «работа над ошибками» — и в пуле, и в каждом наборе;
- **тег у каждого вопроса** — откуда взят правильный ответ;
- **таблица лидеров** внизу главной — соревнование по числу верных ответов;
- офлайн-версия одним файлом (`gos-exam-tests-offline.html`), интернет не нужен.

## Теги: откуда взят правильный ответ

| Тег | Что значит | Вопросов |
|---|---|---|
| ✅ Подтверждён | Ответ размечен в исходном файле и прошёл независимую проверку | 5 665 |
| 🖍 Выделен в файле | Ответ подсвечен маркером в исходном PDF (аннотации) | 532 |
| 🔑 Восстановлен | Ключа в файле нет; применено правило «верен первый вариант», проверенное сверкой с базой | 2 515 |
| 🤖 Ответ ИИ | Ключа нет и правило не работает — ответ выбран моделью, стоит перепроверить | 122 |
| ⚠️ Спорный | Разметка исходника противоречива | 64 |

В настройках теста можно оставить только проверенные вопросы либо, наоборот,
только те, что требуют проверки.

## Таблица лидеров

По умолчанию рейтинг собирается из профилей **этого устройства**: на общем
компьютере или планшете группы соревнование работает сразу, никуда ничего не
отправляется. Места распределяются по числу верных ответов, при равенстве —
по точности.

Чтобы студенты соревновались с разных телефонов, нужен общий список
результатов. Готовый обработчик — `server/leaderboard-worker.js`
(Cloudflare Worker + KV, разворачивается бесплатно):

```bash
npm create cloudflare@latest gos-exam-board   # положить туда файл как src/index.js
npx wrangler kv namespace create SCORES       # id прописать в wrangler.toml
npx wrangler deploy
```

Затем вписать адрес в `config.js`:

```js
window.LEADERBOARD_URL = "https://gos-exam-board.<ваш>.workers.dev/scores";
```

Контракт: `GET` возвращает `[{name, solved, correct}, …]`, `POST {name, slug,
solved, correct}` сохраняет результат. Если адрес недоступен, сайт молча
показывает локальную таблицу.

## Сборка

```bash
python3 scripts/build_site.py     # исходники -> data/*.json + manifest.json
python3 scripts/verify.py         # независимая проверка ключей
python3 scripts/build_offline.py  # офлайн-версия одним файлом
```

Вспомогательные скрипты: `parse.py` (файлы с разметкой), `highlights.py`
(ключ из выделений в PDF), `sources_unanswered.py` (файлы без ключа),
`matching.py` (сопоставление вопросов, в том числе узбекская латиница ↔
кириллица), `check_unanswered.py` (проверка гипотезы «верен первый вариант»),
`build_extra.py` (наборы без обычной разметки).

Ответы модели лежат в `data/ai_answers.json` (`хеш вопроса -> индекс ответа`),
список неотвеченных: `python3 scripts/build_extra.py --pending`.

## Структура

```
data/            банки вопросов + manifest.json + ai_answers.json
js/              i18n, storage (профиль и прогресс), data, ui, app
scripts/         сборка и проверки
sources/         исходные файлы (в git не попадают)
```

Формат вопроса:

```json
{ "q": "текст", "options": ["…"], "correct": [0], "tag": "verified" }
```

`correct` — список: часть вопросов имеет несколько правильных ответов.
