# Гос экзамен — тесты

Тренажёр для подготовки к государственному экзамену: терапия, педиатрия,
хирургия, детская хирургия.

**Сайт:** https://temurturayev.github.io/gos-exam-tests/

- **10 258 вопросов** в 22 наборах;
- **вход по имени** — прогресс каждого человека хранится отдельно;
- **два языка**: интерфейс и тесты переключаются между русским и узбекским;
- **общий пул** — все предметы вперемешку, с памятью решённого;
- фильтры «только нерешённые» и «работа над ошибками» — и в пуле, и в каждом наборе;
- **тег у каждого вопроса** — откуда взят правильный ответ;
- **таблица лидеров** внизу главной — соревнование по числу верных ответов.

## Теги: откуда взят правильный ответ

| Тег | Что значит | Вопросов |
|---|---|---|
| ✅ Подтверждён | Ответ размечен в исходном файле и прошёл независимую проверку | 5 613 |
| 🖍 Выделен в файле | Ответ подсвечен маркером в исходном PDF | 1 204 |
| 🔑 Восстановлен | Ключа в файле нет; применено правило «верен первый вариант», проверенное сверкой с базой | 2 481 |
| 🤖 Ответ ИИ | Ключа нет и правило не работает — ответ выбран моделью, стоит перепроверить | 885 |
| ⚠️ Спорный | Разметка исходника противоречива | 75 |

В настройках теста можно оставить только проверенные вопросы либо, наоборот,
только те, что требуют проверки.

## Таблица лидеров

Общая для всех: результаты хранит Cloudflare Worker из папки `server/`
(развёрнут на `gos-exam-board.temurturayev7822.workers.dev`). Места — по числу
верных ответов, при равенстве — по точности. Счёт участника может только
расти, поэтому сброс прогресса в браузере не обнуляет заработанное.

Если сервер недоступен, сайт молча показывает локальную таблицу по профилям
этого устройства — соревнование не ломается.

```bash
cd server && npx wrangler deploy        # обновить обработчик
npx wrangler secret put ADMIN_TOKEN     # задать ключ очистки таблицы
```

Очистить таблицу перед новым потоком либо убрать одного участника:

```bash
curl -X DELETE https://gos-exam-board.temurturayev7822.workers.dev/scores \
  -H "x-admin-token: <ваш ключ>"
curl -X DELETE https://gos-exam-board.temurturayev7822.workers.dev/scores/temur \
  -H "x-admin-token: <ваш ключ>"
```

Адрес сервера задаётся в `config.js`. API: `GET /scores` возвращает
`[{name, solved, correct, updated}, …]`, `POST /scores {name, solved, correct}`
сохраняет результат, `DELETE /scores` с ключом очищает таблицу, `DELETE /scores/<имя>` убирает
одного участника, не трогая остальных.

## Сборка

```bash
python3 scripts/build_site.py     # исходники -> data/*.json + manifest.json
python3 scripts/verify.py         # независимая проверка ключей
```

Вспомогательные скрипты: `parse.py` (файлы с разметкой), `highlights.py`
(ключ из выделений в PDF), `sources_unanswered.py` (файлы без ключа),
`matching.py` (сопоставление вопросов, в том числе узбекская латиница ↔
кириллица), `check_unanswered.py` (проверка гипотезы «верен первый вариант»),
`build_extra.py` (наборы без обычной разметки), `migrate_ai_answers.py`
(перенос ответов модели после изменения разбора).

В PDF длинный вопрос занимает две строки. Без склейки его хвост становился
отдельным вариантом ответа — и по правилу «верен первый вариант» ещё и
правильным. Строки склеиваются по правому краю текста (95-й процентиль
ширины строк), а вопрос считается законченным на строке с `:` или `?`.
Вариант, заканчивающийся двоеточием, на сайт не попадает ни при каких
условиях — это страховка от подобных ошибок разбора.

Ответы модели лежат в `data/ai_answers.json` (`хеш вопроса -> индекс ответа`),
список неотвеченных: `python3 scripts/build_extra.py --pending`.

## Структура

```
data/            банки вопросов + manifest.json + ai_answers.json
js/              i18n, storage (профиль и прогресс), data, ui, app
scripts/         сборка и проверки
sources/         исходные файлы (в git не попадают)
```

Формат вопроса:

```json
{ "q": "текст", "options": ["…"], "correct": [0], "tag": "verified" }
```

`correct` — список: часть вопросов имеет несколько правильных ответов.
